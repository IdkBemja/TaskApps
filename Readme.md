
# Tasks App

a simple tasks assigment made with python flask. this app was a final exam for bootcamp




## Features

- Login / Register System
- Add / Edit Tasks
- Display Current / pending / past Tasks

## Installation

Install with python

```bash
  python3 -m venv taskapp-env
  source taskapp-env/bin/activate
  pip install -r requirements.txt
  git clone https://github.com/IdkBemja/TaskApps.git
  cd TaskApps
```
